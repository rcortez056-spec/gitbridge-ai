# GitBridge AI

A lightweight GitHub-to-Slack bridge designed to streamline developer team notifications using Kiro's spec-driven development environment.

## Overview
GitBridge AI bridges the gap between GitHub repository events and Slack channels, ensuring your team stays instantly updated on pull requests, issues, and commits without wading through noisy feeds.

## Features
* **Automated Alerts**: Real-time Slack notifications for GitHub webhooks.
* **Kiro Integration**: Built utilizing Kiro's structured `/.kiro` steering framework.
